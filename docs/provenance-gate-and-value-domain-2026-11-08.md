## 1. 相近工作定位（arXiv 侦察，2026-11-08）

| 工作 | 做法 | 与本文关系 |
|---|---|---|
| **ECHOES**（arXiv:2610.22408） | 历史截图=训练期特权信息；CTA 递归文本状态；OPD-RL（GRPO+特权蒸馏）把「看过多图」的决策蒸馏进权重；部署态只留任务指令+当前截图+自生成状态 C | **最近邻**。同动机（文本摘要丢关键视觉状态），不同机制：需训练权重、部署不可取回像素、测 PMF 保真缺口 |
| MemU-Bench/AppMem（arXiv:2611.00191） | 跨会话用户历史→结构化记忆库+选择性检索；免训练 | 问题域不同（用户历史 vs episode 内视觉证据）；「免训练 GUI 记忆」话术空间被占，须区分 |
| GHD（arXiv:2608.06065） | 训练期后见蒸馏（教师看下一屏）改进模仿学习 | 训练方法；非推理时上下文管理 |
| Chart the Invisible（arXiv:2610.35237） | 视口隐藏目标探索（滚动揭示） | 「看不见的视觉信息」相邻但不同问题 |
| Darwinian Memory / HiconAgent / Less is More / STAMP / GUIFlow / DeltaReplay 等 | 记忆系统/历史感知策略/上下文简化 | 各取一角；无「瞬时像素独占线索+证据溯源保留」组合 |

**结论**：「文本摘要丢视觉状态」动机已被 ECHOES 公开占据；贡献必须落在**免训练、可取回、溯源闭环**的机制上，且价值域实验证明其不可替代性。

## 2. 创新贡献（论文主张）

### 贡献 A：瞬时像素独占线索的受控机制探针（分析）
canvas 独占瞬时线索（promo 码）+ 文本通道恒保真不变量，把「图像逐出丢证据」隔离为单通道可归因问题；三路因果归因（被动保留/显式取回/摘要抄录）给出恢复通路。已有证据：蒸馏承载恢复（41/47）、取回低频高效（自发 ~12%、调后 10/10 成）、锚定/新鲜度正交（批次 4 消融）。

### 贡献 B：证据溯源闸门 Provenance Gate（方法，核心创新）
**把归因机制变成闭环**：事后归因里已判定「输入值有没有上下文出处」——把这个判定搬到动作执行时刻，形成**出处闸门**：

- **溯源账本**（已在产线半数就位）：每帧本地原始引用不删；摘要蒸馏记录 source_steps；保留/逐出/钉住状态全程可知。
- **无出处判定（不依赖 ground truth）**：type_text 提交值 V 时，检查 V 是否在本次请求的证据文本里有出处（保留帧的控件树文本、摘要文本）。V 无出处 = 在替模型记忆里「凭空」出现（猜/幻觉/丢失后编造）。
- **闸门动作（软触发，不越权）**：返回提示「值 V 在当前上下文无出处；本地留存帧可回看取证」+ 候选步号（优先：该字段值曾可能出现的已逐出帧——按溯源账本的蒸馏源步与未蒸馏逐出帧排序）。agent 可继续（确认）或 review_screenshot 取证。**只浮出模型自己历史观察的证据，不注入任何答案**——研究环境无 fault/expected 泄漏（证据=agent 自己的旧截图，合法）。
- **与既有闸门的对偶**：confirm_and_tap 是**权限闸门**（副作用需人确认）；Provenance Gate 是**证据闸门**（无出处值需取证）。同为 fail-closed：无人值守下出处闸门只提示不阻断（阻断策略属消融）。
- **与 ECHOES 的本质差异**：ECHOES 部署态丢弃像素、错误状态无法修复（PMF 缺口即永久）；本文溯源可回看、可重观察、可纠错——冻结权重模型（API 模式）即可用。
- **与 prompt 提示（批次 5 nudge）的关系**：nudge 是弱形式（把「不确定→回看」写进 system，靠模型自觉）；Provenance Gate 是强形式（harness 在无出处时刻确定性触发）。批次 5 的 A/B 提供「弱形式够不够」的直接证据。

## 3. 价值域实验设计（命门实验）

**问题**：在什么历史规模/预算下，full 历史不可用（上下文溢出或成本爆炸），而证据溯源压缩仍保恢复？

### 3.1 长任务族（research-env 扩展，不动 app 二进制语义，只加任务组合）
- **T1 多轮下单**：一个 episode 内完成 K 轮「浏览→加购→结算」（K=2/4/8），瞬时线索随机出现在某一轮首屏，收银台在后续轮次。历史长度 ~K×8 步。
- **T2 全目录巡览**：遍历全部商品详情并按参数条件下单（记忆商品参数），历史长度 ~2×商品数。
- **T3 长清单**：加购 N 件、按约束筛选后结算（N=4–8），中间反复列表/详情切换。
- 线索过期语义不变（首动作即过期）；成功检查仍基于业务状态+目标参数。

### 3.2 预算墙口径（判据先声明，防事后挑点）
- **上下文墙**：full 臂在历史装入后请求长度逼近模型上下文上限（实测 MiMo 端点限制并记录；逼近率 ≥90% 记为撞墙点）。
- **成本墙**：full 臂未缓存输入 ≥ 压缩臂的 3 倍且恢复率不占优（3 倍为预设判据，非事后选择）。
- 曲线网格：历史长度 N ∈ {12, 24, 48, 96} 步 × 策略 {full, recent1sum3(或扫参最优), evidence2sum3, Provenance Gate 变体} × 预算 {1,2,4}。
- 全曲线报 token 四类分列 + 恢复率 + 步数；cold/warm 分列（缓存前缀效应随历史增长）。

### 3.3 统计
任务族/模板为聚类单位，聚类 bootstrap 置信区间；符号检验做配对下界。失败留档（API/invalid_reset/离机制失败）不剔除，报告口径不变。

## 4. Provenance Gate 评估协议

| 臂 | 组成 | 回答 |
|---|---|---|
| recent1（仅重试） | 地板（既有 0/12） | — |
| recent1sum3 | 蒸馏（既有 11/12） | 蒸馏单通道 |
| recent1sum3+nudge | 蒸馏+提示（批次 5 在跑） | 弱形式够不够 |
| recent1sum3+PG | 蒸馏+出处闸门（新） | 强形式增益 |
| recent1retr+PG | 无蒸馏+出处闸门 | 闸门能否救蒸馏缺失域 |
| full | 天花板（既有 12/12） | — |

- **指标**：恢复率（业务状态）、码/值通道正确率、无出处值触达率与闸门命中率（触发时值确无出处的比例）、假触发率（值有出处却被提示）、取回调用率变化、成本四类。
- **消融**：闸门硬阻断 vs 软提示；候选帧排序（蒸馏源步优先 vs 时间序）。
- **压力设置**：蒸馏失效率被 M=6/截断/长历史抬高处测 PG 增益（M=2/3/6 扫参数据选点）。
- **安全边界**：闸门文本不得含 fault_id/expected_answer/路径提示；触发依据只用 agent 可见历史的派生账本；无人值守不阻断（fail-closed 口径与既有闸门一致）。
